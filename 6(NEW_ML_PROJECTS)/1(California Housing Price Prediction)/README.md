# California Housing Price Prediction

## Project Overview
This project is an end-to-end machine learning workflow that predicts housing prices in California based on features like location, population, and number of rooms. It demonstrates data collection, visualization, preprocessing, feature engineering, model training, hyperparameter tuning, and evaluation.

## Key Steps
1. Data Collection
2. Data Exploration & Visualization
3. Data Preprocessing & Feature Engineering
4. Model Training
5. Model Evaluation
6. Feature Selection
7. Final Predictions

## Tools & Libraries
- Python 3.5+
- Pandas, NumPy
- Matplotlib
- Scikit-learn
- SciPy

## Key Features
- End-to-end workflow
- Handles missing data & categorical variables
- Includes feature engineering
- Multiple regression algorithms & hyperparameter tuning
- Produces interpretable results
